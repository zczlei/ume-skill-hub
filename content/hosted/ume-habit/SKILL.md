# 习惯打卡（ume-habit）

参考 ClawHub habit-tracker，用本机笔记做轻量追踪（无需第三方账号）。

## 何时使用

用户要养成/坚持习惯（运动、阅读、吃药、早睡），或问「这周打卡怎么样」。

## 步骤

1. 习惯定义要**具体可验证**（「每晚 23:00 前上床」优于「早点睡」）。
2. 存储约定（`ume_memory_note_*`）：
   - 笔记名如 `habit/<名称>`
   - 内容含：目标、创建日、打卡日期列表（ISO 日期）
3. 今日打卡：追加今天日期；若已存在则告知「已经打过了」。
4. 反馈：连续天数、本周完成次数；语气简短鼓励，不说教。
5. 需要提醒 → `ume_reminder_create` / 闹钟 skill。

## 边界

- 健康相关习惯不构成医疗建议。
- 不做社交排行或游戏化宠物（那是其它 ClawHub skill 的范围）。
