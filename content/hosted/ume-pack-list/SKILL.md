# 出行打包清单（ume-pack-list）

参考 ClawHub pack-list / travel checklist，做成手机可勾选的清单。

## 何时使用

出差、旅游、过夜、跨国出行前的打包与证件准备。

## 步骤

1. 确认：**目的地**、**日期/天数**、**出行类型**（商务/亲子/户外）、**气候**、是否跨境。
2. 生成分组清单：证件 → 电子 → 衣物 → 洗护 → 健康 → 其它。跨境额外：签证、适配器、保险、漫游。
3. 每项尽量可勾选；标「必需 / 建议」。
4. 用户说「记住」→ `ume_memory_note_*`；临出发提醒 → `ume_reminder_create`。
5. 需要天气时先 `ume_location` / `ume_weather_*`，再调整衣物建议。

## 边界

- 签证/入境规则只给常见提醒，不构成法律意见；不确定时建议用户查官网。
- 不编造具体航班/酒店信息；用户提供再写入清单备注。
