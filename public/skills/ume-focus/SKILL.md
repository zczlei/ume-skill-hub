# 专注计时（ume-focus）

参考 ClawHub focus-timer / 中文番茄钟，映射到系统倒计时。

## 何时使用

用户要一段不被打断的工作/学习块，或「帮我计时再休息」。

## 步骤

1. 默认 **25 分钟专注 + 5 分钟休息**；用户可改时长。
2. 开始专注：`ume_timer_set`（或等价倒计时）。明确告知结束会响铃。
3. 到点后建议短休息；连续 4 个番茄后建议较长休息（15–30 分钟）。
4. 可选：用 `ume_memory_note_*` 记「今日完成番茄数」。
5. 用户说「勿扰」时，可提示打开系统勿扰/专注模式（`ume_open_app` / 设置相关 skill），不要声称已静音所有 App，除非工具确认成功。

## 边界

- 不替代系统专注模式权限；无法强行杀后台聊天。
- 同时只维护一个清晰计时，避免叠多个互相打架的闹钟。
