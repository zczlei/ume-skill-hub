# 会议纪要（ume-meeting-notes）

改编自 ClawHub `meeting-notes` 工作流，适配微米 AI 手机侧（粘贴文本 / 文档 / 字幕）。

## 何时使用

例会、项目评审、客户沟通后，用户给出录音转写、微信/飞书聊天导出、Word/PDF 会议稿。

## 步骤

1. 取得原文：用户粘贴，或 `ume_pdf_summary` / `ume_office` / 聊天截图 OCR。
2. 只提取原文已有信息，**不编造**时间/参会人/决议。
3. 按模板输出：

```markdown
# 会议纪要：<主题>

- 时间：
- 参会人：

## 决议事项
1. …

## 行动项
| 事项 | 负责人 | 截止 | 备注 |
|------|--------|------|------|

## 遗留问题
1. …
```

4. 行动项负责人不明时写「待确认」。信息不足的章节直接省略，不要写「无」。
5. 用户说「记下来」→ 用 `ume_memory_note_*` 存纪要；有明确截止 → `ume_reminder_create` / 日程。

## 边界

- 不替代正式会议系统；法律/合同结论需用户复核。
- 录音本身不在本 skill 内转写；先由用户或其它能力给出文本。
