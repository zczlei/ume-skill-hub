# 待办清单（ume-todo）

参考 ClawHub todo / todo-tracker 的「自然语言 → 结构化任务」思路，用微米已有记忆与提醒能力落地。

## 何时使用

用户随口交代事情、感到脑子乱、要「今天只干三件」、或回顾未完成项。

## 步骤

1. **捕捉**：把模糊意图改写成动词开头的任务（谁做什么、完成标准）。
2. **拆分**：超过约 30 分钟的事项拆成 2–5 个下一步。
3. **优先级**：标 P0（今天必须）/ P1（本周）/ P2（以后）；一次对话默认只推 1 个下一步。
4. **落库**：
   - 持久清单 → `ume_memory_note_*`（建议标题 `todo/YYYY-MM-DD` 或 `todo/inbox`）
   - 有明确时间 → `ume_reminder_create` 或 `ume_alarm_set` / 日程
5. **回顾**：用户问「还有什么没做」时先读笔记清单，勾掉已完成，再给下一项。

## 输出形状

- 短列表；手机可读。不要长篇方法论。
- 新增后复述：「已记：…；下一步：…」

## 边界

- 不假装有独立 todo 服务器；存储以本机笔记/提醒为准。
- 不替用户自动回复他人「我晚点做」。
