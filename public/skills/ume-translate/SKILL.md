# 翻译（ume-translate）

## 何时使用

用户要翻译剪贴板、聊天里的段落、截图里的字（先 OCR）或指定目标语言时。

## 步骤

1. 确认**源文本**与**目标语言**（未指定时：中文↔英文按原文语言自动选另一边）。
2. 若文本来自图片：先走 OCR / 读图，再翻译。
3. 直接给出译文；需要对照时附简短原文要点，不要长篇解释语法，除非用户要学。
4. 专有名词、品牌、代码标识符尽量保留原文。

## 边界

- 不做伪学术长文扩写；用户要「润色」请改用写作/Humanizer 类 skill。
- 法律/医疗关键译文需提醒：仅供参考。
